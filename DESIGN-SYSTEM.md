# Justice Brutus Portfolio Design System

## Point of view

A restrained engineering dossier: calm corporate typography, disciplined rules, adjacent claim-and-evidence layouts, minimal motion, and direct recruiter reading. It intentionally does not reuse Meridian’s cream, forest, serif, or cinematic visual identity.

## Foundations

- Manrope carries product narrative; IBM Plex Mono carries labels, indices, and evidence metadata.
- Ink, slate, cool paper, white, and institutional blue form the core palette. Amber is reserved for visible focus.
- Hairline rules and measured negative space replace decorative card grids.
- The maximum content frame is 1240px with fluid gutters and section spacing.

## Composition

- Home: identity → Meridian → Carryover → capabilities → Technical Lab → operating context → contact.
- Case studies place each claim adjacent to system, route, test, or responsive evidence.
- Desktop preserves comparison; tablet reduces parallel information; mobile returns to direct document order.
- Project media uses fixed aspect ratios and dimensions to prevent layout shift.

## Interaction and access

- Native links, buttons, address, headings, figures, lists, and form semantics.
- Visible keyboard focus and a skip link.
- 44px minimum primary controls on mobile.
- Navigation becomes an explicit mobile menu.
- Motion is limited to short image hover feedback and is removed under reduced motion.

## Résumé and print

The résumé is a single semantic source rendered on the web and printed to one US Letter page. Print rules remove site navigation, flatten presentation, keep text selectable, and preserve ATS reading order.

## Voice

Specific, evidence-led, and calm. No unsupported seniority, user, revenue, conversion, or business-impact claims. AI-assisted development appears only in precise process disclosure, while ownership of requirements, trade-offs, acceptance, and release remains explicit.
