# Justice Brutus — Frontend Developer & UI Engineer

**Live:** https://justice-portfolio-nine.vercel.app

A recruiter-facing engineering dossier led by two released flagships:

- **Meridian Capital** — a 27-route fictional institution and five-workspace portfolio operating system with 46 passing tests.
- **Carryover** — a role-aware shift-continuity product with five workspaces, a real handoff workflow, versioned persistence, 25 unit tests, and 105 cross-browser checks.
- **Technical Lab** — compact Luxen Mix Analyzer and HALO records demonstrating browser-audio, Canvas, motion, and performance range.

## Routes

- `/` — skimmable hiring summary, Meridian evidence, operating experience, and technical range.
- `/work/meridian` — complete Meridian case study.
- `/work/carryover` — Carryover workflow, architecture, responsive evidence, and verified release record.
- `/resume` — semantic, print-ready résumé.
- any unmatched route — deliberate 404 recovery.

## Run

```bash
npm install
npm run dev
npm test
npm run build
```

## Quality

The portfolio uses shared typed profile, project, case-study, evidence, and résumé records so claims do not drift between surfaces. It includes keyboard navigation, visible focus, reduced-motion behavior, responsive recomposition from 320px through desktop, route-specific metadata, print styles, and a selectable one-page PDF résumé.

See [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md) and [UI-AUDIT.md](UI-AUDIT.md) for the design and verification record.
